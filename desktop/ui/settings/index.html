Triggers

Rebinding shortcuts in-app is on the roadmap. For now, these are registered at startup. To change one, edit settings.json in your userData folder.

Ctrl+MAsk Claude (Chrome extension)
Ctrl+Shift+VVoice toggle (start / stop recording)
Ctrl+BShow / hide overlay
Ctrl+HToggle history rail
Ctrl+LClear current answer
Ctrl+↑↓←→Nudge overlay 40px
Ctrl+1…5Switch prompt mode (see Prompts tab)

Voice

Trigger

Enable voice trigger
Press Ctrl+Shift+V to start, press again to stop.
30 s
⚠
OpenAI API key required
Add it in the API & Models tab to use voice.

Audio is sent to OpenAI for transcription, then the transcript is sent to Claude. Roughly $0.006 per minute of audio at current Whisper-1 pricing.

Prompts

Click a card to make it active. Each captures the active Chrome window (Ctrl+M) using that system prompt. Voice queries always use the dedicated voice prompt.
