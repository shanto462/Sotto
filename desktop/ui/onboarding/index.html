Welcome to Sotto

Press Ctrl+M in Chrome — Sotto captures the window, asks Claude to explain or recap it, and shows the answer in an overlay that's hidden from screen-share.

System permissions

Required by macOS / Windows for capture, voice, and shortcuts.

⚠
Running unpackaged — permissions will be granted to your terminal app
macOS attributes permission prompts to the process that launched Electron (e.g. Terminal, iTerm, Ghostty). For permissions to scope to "Sotto" specifically, run npm run package once and launch dist/mac/Sotto.app.

/path/to/sotto/extension
  1. Click Open chrome://extensions below.
  2. Find Sotto in the list.
  3. Click the ↻ reload icon on its card.
  4. Open or refresh any web page — the heartbeat fires immediately.

A reload is needed after Sotto updates the extension (e.g. new permissions or a new background script).
